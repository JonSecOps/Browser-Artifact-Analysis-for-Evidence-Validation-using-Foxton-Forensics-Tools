# Browser Artifact Analysis for Evidence Validation using Foxton Forensics Tools

**Project Summary**

This project involved conducting a digital forensic investigation of browser artifacts in an attempted murder case scenario. Acting as a forensic examiner assisting the New York State Police, the task was to determine whether digital evidence supported a husband’s claim that his wife had poisoned him. Using Foxton Forensics Browser History Viewer and SQLite Studio, the examiner analyzed cached webpages, typed searches, download history, and session data from multiple web browsers (Google Chrome, Mozilla Firefox, and Microsoft Edge) belonging to both spouses.

The forensic analysis revealed that while Arlene’s browsing activity was unrelated to the alleged poisoning, Robert’s activity included searches on toxic substances, arsenic poisoning, pufferfish (tetrodotoxin), and lethal dosage information. The evidence contradicted Robert’s claim and suggested possible self-poisoning or an accidental ingestion. The project demonstrated the importance of web artifact analysis in reconstructing user behavior and supporting criminal investigations.

**Learning Points**

1. Learned to utilize Foxton Forensics Browser History Viewer for the extraction and examination of cached webpages, downloads, and search histories.
2. Gained experience using SQLite Studio to validate and manually query browser databases.
3. Developed skills in identifying digital evidence relevance and correlating web activity to behavioral patterns in forensic investigations.
4. Understood how browser artifacts from multiple users on a shared system can provide distinct investigative leads.
5. Strengthened ability to document findings and draw data-driven conclusions that support or refute investigative hypotheses.
6. Enhanced understanding of how browser forensic analysis aids in verifying or disproving suspect testimony in criminal cases.

**Key Skills Developed**

1. **Web Browser Forensics** – Extracting and analyzing browsing data, cached files, and search histories from multiple browsers.
2. **Digital Evidence Analysis & Correlation** – Interpreting user behavior and intent from browser activity.
3. **Forensic Tool Proficiency** – Practical experience with Foxton Forensics Browser History Viewer and SQLite Studio.
4. **Analytical & Critical Thinking** – Evaluating data objectively to assess competing narratives in a criminal case.
5. **Forensic Reporting** – Compiling a structured, court-ready report documenting methodology, findings, and conclusions.
6. **Data Validation & Verification** – Cross-referencing tool output with underlying databases to ensure accuracy and evidentiary integrity.
